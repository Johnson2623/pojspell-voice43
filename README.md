# AI 跨界音樂元素工作站 v31 (Cross-Genre Music Elements Studio)

## v31 更新說明（文章 / Word / PDF / 文案 / 網址 轉歌詞工作室）
1. **支援多元文本來源匯入（步驟 1 ＆ 步驟 4 雙入口同步）**：
   - **上傳文件（`.txt` / `.docx` / `.pdf`）**：瀏覽器端直接解析純文字檔、Word 文件（透過 Mammoth.js）與 PDF 文件（支援 PDF.js 文字萃取，且填入 API Key 時可直接將 PDF 原檔傳給 Gemini 多模態閱讀）。
   - **貼上文章／文案／現成歌詞**：可直接貼上尚未成詞的散文、故事、企劃書或現成歌詞，並選擇「✨ 文章提煉轉歌詞」或「🔄 同格律二創改寫」。
   - **輸入網址連結（URL）**：內建公開網頁正文自動擷取功能，貼上文章連結一鍵帶入全文。
2. **有 API Key 走 Gemini AI 深度改編、無 Key 走離線提煉生成**：
   - **有 API Key**：自動讀懂全文主旨，提煉新歌名與 4 個核心關鍵詞，並嚴格依照步驟 2 曲風與步驟 4 曲式段落順序改編為押韻可唱歌詞。
   - **無 API Key**：自動執行離線關鍵詞與核心金句萃取，按步驟 4 曲式段落編排生成歌詞草稿並自動跳轉至步驟 4 檢視。
